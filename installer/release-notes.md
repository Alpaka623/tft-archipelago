## Install

Download `TFT-Archipelago-Setup-{version}.exe` below and run it. It installs for your Windows user only, without admin rights. The installer is not signed yet: if Windows SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

Already installed? The app updates itself. The update installs when you close the app, or right away with **Restart** at the bottom of the sidebar.

## Multiworld Files

- `tft_archipelago.apworld`: the APWorld for whoever generates the multiworld. Double-click it to install it into Archipelago 0.6.5 or newer.
- `TFT-Archipelago-template.yaml`: the player options template. The app's **Setup** page also creates a YAML for you.
