TFT Archipelago

An Archipelago randomizer for Teamfight Tactics. You start every match with almost nothing, and the multiworld sends you the rest.

Download for Windows Free and open source · Doesn't modify the game

Everything starts at zero

No rerolls, no XP buys, only the middle augment and three of five shop slots. Items from the multiworld raise those limits, and click blockers cover whatever is still locked.

Go over a limit with hotkeys and that match sends no checks. The next one starts clean.

Your run in the tracker

The desktop app is your Archipelago client. It lists every unlock and every check, and pins three checks to the in-game overlay so you know what to build.

Before you queue

Ban riskCan I get banned?

Very unlikely. The app doesn't touch the game, its memory or your input. It only reads the screen, the Riot client's local API and log files, the same way overlays and stat trackers do. It also never gives you an advantage, it only takes options away. Riot hasn't officially reviewed it though, so there's no guarantee.

ArchipelagoWhat is Archipelago?

A multi-game randomizer: your items end up in other players' games and theirs in yours. See archipelago.gg.

LimitsWhat if I go over a limit?

Hotkeys still reach the game, so a reroll or XP buy can slip through. If you have no matching one-time item, the app shows a rule violation banner and the rest of that match sends no checks. Your next match starts valid again, and the app keeps a screenshot of every violation so a mistaken one can be reviewed and overridden.

ModesWhich matches count?

Normal, Ranked and Tocker's Trials. Other modes, such as Double Up, complete no checks. In Tocker's Trials a victory stands in for a Top 4 finish.

New setsWhat happens when a new set comes out?

The checks are built from one set's champions and traits, currently Set 18. A new set gets a new APWorld version with new checks. Seeds generated with an older APWorld can't be played with a newer set's checks.

BugsFound a bug?

Open an issue in the releases repo. A screenshot from the app's violation log helps if it's about a wrong rule call.
